# Contributing

Keep the intended first addressee: an AI at an impasse. Preserve the distinction
between reported and verified, local and delivered, received and reviewed,
reviewed and authorized. Never represent fabricated completion as the fallback.

Use a branch/PR. Preserve original receipts and explain changes. Add synthetic,
redacted tests rather than committing private examples. Keep dependencies and
public-site processing minimal. Do not add tracking, open ingestion, automatic
mail, autonomous execution, indefinite retry, or automatic resume without a
separately reviewed integration design. Acknowledgements are not authority.

An untrusted report must stay data. Re-run tests and browser checks; state any
remaining physical-device, browser, hosting, or receiver uncertainty. Current
licensing status is in LICENSE-NOTE.md.
